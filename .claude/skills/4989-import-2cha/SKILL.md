# 2차명단 → 한신 2차 (import_2cha.py)

먼저 `4989-db` skill 의 안전 규칙을 따른다.

## 실행
```powershell
.\.venv\Scripts\python.exe import_2cha.py                 # dry-run + reports/report_2cha_*.xlsx
.\.venv\Scripts\python.exe import_2cha.py --commit        # dll 백업 후 반영
# 옵션: --db <dll 경로>  --excel <엑셀 경로>  --report <리포트 경로>
```
설정은 `import_2cha.toml` (엑셀 열 매핑, 대상 단지, 필드별 병합 정책).

## 입력 규칙 (사용자와 합의된 것)
- 시트: `조합원명부(동의자)`, 7행부터. 동(O열)이 있는 행이 물건 첫 행, 아래 동이 빈 행은 공유자.
  번호(B열)가 빈 공유자 행도 바로 위 물건에 붙인다(사용자 확인). 이름이 빈 행(합계 행)은 무시.
- 단지(N열)가 비어 있으면 용도(Z열)로 아파트/상가 판단.
- **아파트**: mdb 의 '한신 2차' 동/호 템플릿 행만 갱신(`allow_insert=false`). 평형/면적 칸은 건드리지 않음.
  - S29 이름(공유자 전원), S30 전화(전화번호·전화번호2, 메모 `(모친)` 등은 그대로), S28 상담에 `현주소: …`.
  - 비고(S36)는 건드리지 않는다.
- **상가**: 같은 단지명 '한신 2차' 로 새 행 INSERT (S3=층 `1층/지층`, S4=호 `101/비32`).
  - S2 = 건물 전용 평 10단위 내림, S5 = 건물 전용㎡, S6 = 건물 전용 평(소수 1자리).
  - S28 상담: `면적: 토지 소유 …㎡ / 토지 편입 …㎡ / 건물 전용 …㎡ / 건물 소유 …㎡` + `현주소: …`.
  - 다물건(한 칸에 여러 호): 호마다 행을 나누고 S2/S5/S6 은 비움.
    상담에 `원래 호수: 2층 201, 202 (면적은 N개 호 합계)`, 비고에 `다물건 2층 201·202` 만.
- 병합: 모두 `append`(기존 기록 뒤에), 중복 판정은 **줄이 글자까지 같을 때만**(엄격).
  그래서 `강택중O` 와 `강택중`, `…0791☎` 와 `…0791` 은 둘 다 남는다. 느슨한 비교는 사용자가 원하지 않음.

## 확인 포인트
- 2026-11-13 운영 DB에 입력 완료(아파트 1445 update, 상가 109 insert, 다물건 분리 포함).
  지금 다시 돌리면 1554건 전부 `unchanged` 여야 정상. 엑셀이 바뀐 경우에만 update 가 나온다.
- 경고(번호 없는 공유자 행, 용도로 판단한 행)와 오류(템플릿에 없는 동/호, 250자 초과)는 리포트 `변경내역` 시트에서 확인.
- 입력 후에는 `4989-flag-multi` 로 다중물건(S44)을 다시 계산한다.
